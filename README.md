# WebShop mit Produkt und Warenkorb

- Alle angezeigten Produkte sind 5 auf Stock
- wählen Sie bitte mehr als 5 Stück des Produkts und beobachten Sie, was passiert
## Anwendung

```
# Abhängigkeiten installieren
$ npm install

# Kompilieren und Hot-Reload für die Entwicklung
$ npm run dev --> dann http://localhost:5173/ aufrufen

# minification
$ npm run build

# Vite preview
$ npm run serve
```
